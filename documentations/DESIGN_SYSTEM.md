# Portfolio Design System

## Visual language
- Primary accent: blue
- Neutral surfaces: white/slate with matching dark mode
- Large section radius: `rounded-[2rem]`
- Control radius: `rounded-xl`
- Standard section width: `max-w-7xl`
- Standard section spacing: `py-24`

## Shared classes
- `section-shell`
- `section-kicker`
- `section-title`
- `section-copy`
- `surface-card`
- `surface-card-hover`
- `btn-primary`
- `btn-secondary`
- `btn-dark-secondary`
- `icon-button`
- `tech-pill`

Use these classes for future sections so the portfolio remains visually consistent.
