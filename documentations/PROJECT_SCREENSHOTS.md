# AI Video Summarizer screenshot setup

Create this folder inside the portfolio:

```text
public/projects/
```

Add these three screenshots:

```text
public/projects/ai-video-summarizer-desktop.png
public/projects/ai-video-summarizer-summary.png
public/projects/ai-video-summarizer-mobile.png
```

Recommended captures:

1. `ai-video-summarizer-desktop.png`
   - Browser width: 1440 px
   - Show the input field, transcript, and generated summary together.
   - Crop away browser bookmarks and personal tabs.

2. `ai-video-summarizer-summary.png`
   - Focus on the generated summary and its action buttons.
   - Use a realistic public YouTube video rather than test text.

3. `ai-video-summarizer-mobile.png`
   - Browser/device width: 390 px
   - Show the responsive summary view.
   - Capture the full product UI without browser developer tools.

Use PNG or WebP. Keep each image below roughly 500 KB where possible.

The updated component handles missing screenshots gracefully, so the page will not crash while the files are being added.
